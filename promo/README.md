# ことのえだ — 紹介映像

アプリの映像。1920×1080・30fps・約116秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリ ことのね の映像（`../../作成したもの/hanjaatume/promo`）と ことのは の映像（`../../english/promo`）に
そろえた：アプリの画面を描き直し、その横に一文ずつ言葉を置く。

見る人：友だちとの반말から韓国語に入って、話せても해요体まで、という人たち。目上の人の前で言葉が出てこないのは、語尾では
なく 말씀・잡수시다 のような語が足りないから。その語を、文と人と声で身につけていく流れを、アプリの画面で見せる。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | わたし → 친구「잘 자.」。わたし → 할머니 に「할머니, 잘」まで打って止まる | 友だちとの반말なら、話せる。/ でも、目上の人の前だと、言葉が出てこない。 |
| | 上げてみる の「おやすみ」が三段、下から一段ずつ（잘 자. → 선배, 잘 자요. → 할머니, 안녕히 주무세요.）、アプリの声で。주무세요 に色、上に 자다 | 同じひとことでも、相手が上がると、言葉ごと替わる。 |
| | 枝が八つ並ぶ（먹다 › 드시다 › 잡수시다、밥 › 식사 › 진지 …） | 足りないのは、語尾ではなく、語。 |
| 名前 | アイコンと ことのえだ | 友だちに言えることを、目上の人にも。 |
| 浴びる | 食べる・飲む の雨：段（浴びる → 上げてみる → 場面で言う）、枝、流す。文が一つずつ降る（eat.1〜eat.7） | 文が、雨のように降ってくる。/ 誰に話しているか、誰のことか。色の付いた語の上には、ふだんの語。 |
| | 친구 → わたし「우리 할머니는 아침을 꼭 드셔.」（친구のおばあさんのこと）が光り、アプリの声で | 반말でも、話の中の目上の人は上げる。/ 語尾は、話す相手で。上の語は、話の中の人で決まる。 |
| 枝 | 드셔 を押すと 드시다 の枝：먹다 › 드시다 › 잡수시다 が下から一段ずつ、その語の声と | どの語の上の語かが、ひと目で。 |
| 上げてみる | ご飯、食べた？ を 친구 → 선배 → 교수님 → 할머니。替わった字に下線、上の語が一段上がる。いちばん上で 할머니 の返事 | 相手を替えると、同じひとことが段を上る。/ 上げるのは、こちらだけ。相手は、いつもの言い方で返す。 |
| 場面で言う | 下宿の夕飯。「할머니 밥 먹었어요? 나는 友だちと食べてきた。」と打つ → 「할머니, 진지 드셨어요? 저는 친구랑 먹고 왔어요.」。雨で出会った 진지・드시다 は紫。할머니 の返事 | 人と場面が渡される。自分なら、どう返す？ / 出てこないところは、日本語のままで。/ その人に合う言い方に直る。雨で出会った語は、紫で戻ってくる。 |
| | 数日後、窓ぎわのお客さん：「네, 두 분 다 따뜻한 커피 드신대요.」そのままで自然、上の語 2（自分で使った 2） | 数日後、別の場面で。今度は、自分から。 |
| 自分 | これまで、できたこと（드시다：前は AI が補った）、場面のやりとり | AIが補った語を、自分で使えたら。「できたこと」として残る。 |
| 終わり | 名前、タブ | 登録はいりません。記録はこの端末に残ります。 |

文・印・枝は、アプリの中身（`../src/content`）とその関数（`markSpans`・`everydayOf`）をそのまま使う。場面の直しと返事は、
アプリの `/api/turn` が返した本物（`src/scene.json`、2026-10-24）。할머니 の返事は三文で約10秒あったので、映像では初めの
二文で切る。紫は「前に出会った語」：学ぶ人は 食べる・飲む の雨と上げてみる を済ませているので、場面の 진지・드시다 は紫、
はじめての 저・분 はアクセント。自分 の数（浴びた雨 3・場面で言った 2・送った文 2・自分で使えた上の語 2）も、この手持ち
から。

## 声

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。AI は「エーアイ」と書く）。Gemini TTS
  （`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵はアプリの `.env.local`（`GOOGLE_SERVICE_ACCOUNT_KEY`・
  `GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。欠番：V07・V11（理由は台本に）。
- 枝の段の 먹다・드시다・잡수시다（K01〜K03）は韓国語の発音で、段が伸びるときに一つずつ。韓国語の語ひとつは別の語になる
  ことがあるので、生成器は書き起こし（`gemini-2.5-pro`）が台本と一致するまで作り直す。日本語の行は `--check` で書き起こして
  台本と並べた（聞き違えられた行は言い方を替えた：台本の note）。
- 韓国語の文は、アプリの声そのもの（`public/app`：アプリの `public/audio` のクリップを、アプリと同じ名前で）。わたしの文は
  女声（@f）。ナレーションはその上に重ねない。할머니 の返事は、アプリでは AI が書くので、`scripts/assets.mjs` が
  `../src/lib/tts.ts` でその人の声に読ませる。
- 映像の時は、声の長さから決まる（`src/voice.json` と `src/audio.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
- 耳で聞いての確かめ（声の感じ・速さ・韓国語の発音の自然さ）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アプリの声とアイコン、할머니 の返事の声、字（Google Fonts の倉庫から取り、映像に出てくる字だけに切る。Python の fontTools）
npm run voice      # ナレーション（まだ無いクリップだけ。--force・--only V01,K01・--check・--durations）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonoeda-promo.mp4
npm run stills -- 300 1540     # 1コマずつ out/stills に
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。アプリの見た目や言葉を変えたら、ここも変える。
- いつ何が起きるかは `src/timeline.ts`。打つ長さは打ち方（`src/anim.ts` の mixTyping：ハングルは字母から組み上がり、日本語は
  かなで打ってから漢字に替わる）から決まる。時を変えたら `music` を走らせ直す（音楽の最後の和音が終わりのカードに落ちる）。
- 字はアプリと同じ（IBM Plex Sans JP・IBM Plex Sans KR・しっぽり明朝）。言葉を変えたら `assets` を走らせ直す。
- 音楽と小さな音は `scripts/music.py` が作る（姉妹の映像と同じ作り方）。だれかの曲は使っていない。
- 色は `remotion.config.ts` で bt709・yuv420p にしている。Remotion の既定（JPEG のコマ）のままだと全範囲の yuvj420p に
  なり、ブラウザや X で薄い灰色が白く飛ぶ。
